# PresentationEngine

An open-source, high-performance presentation engine in the spirit of ProPresenter: a headless-capable Metal renderer that runs as its own process, drives screen, SDI (Blackmagic DeckLink) and NDI outputs, and is controlled by separate UI clients over a versioned protocol.

The macOS app lives in [PresentationMacUI](https://github.com/jterhorst/PresentationMacUI). This repository holds the engine and the **contracts** every client and plugin builds against.

> **Status:** Phase 0 prototype. Metal compositing, perspective 3D, nine blend modes, RTF text through Core Text, image backgrounds, dissolves, the UYVY/v210 conversion and the counter gate run on Apple silicon. DeckLink output and the protocol server come next ([roadmap](docs/architecture.md#roadmap)).

## Principles

- **The frame is sacred.** The render thread never waits on disk, network, IPC, plugins or the UI.
- **The core stays small.** If a feature can be a plugin or module, it is one.
- **Never regress rendering performance.** CI gates every merge on deterministic counters and timed reference scenes.

## Running the contract checks

Requires Python 3, clang (or cc), and:

```sh
pip install grpcio-tools jsonschema slangpy
tests/run_all.sh
```

## Building the engine (macOS 26+, Apple silicon)

```sh
brew install cmake ninja protobuf googletest
pip install slangpy                      # provides the Slang compiler library
cmake -S . -B build -G Ninja -DPython3_EXECUTABLE=$(which python3)
cmake --build build
build/engine_tests                       # CPU, shader, golden-image and counter tests
build/engined --preview scenes/*.scene.json
```

In the preview window: Right/Space next slide, Left previous, Up/Down switch scene, A replay the scene, C clear all, 1–3 clear background / slide / fixtures.

Other modes: `engined --render <scene> --at <ms> --out f.png`, `--goldens <scenes> --out-dir <dir>`, `--counters <scenes>`.
Regenerate goldens with `ENGINE_UPDATE_GOLDENS=1 build/engine_tests`, the baseline with `ENGINE_UPDATE_BASELINE=1`.
